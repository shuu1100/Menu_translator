# Sample Menus Dataset

This folder contains documented sample menus for testing VLM extraction, translation, and allergen analysis without needing proprietary restaurant records.

## Files
- `sample_menu_metadata.json`: Ground truth metadata, cuisines, dishes, and verified allergen annotations following the safety rules.

## Contributing Samples
When adding new sample menus:
1. Ensure the image is freely licensed (CC0 or public domain).
2. Never store private restaurant recipes or PII in this directory.
3. Keep verified ground-truth annotations separate from inferred VLM outputs.
